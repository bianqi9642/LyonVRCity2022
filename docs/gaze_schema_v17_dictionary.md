# Gaze schema v17: data dictionary and v16 -> v17 disposition

Generated from the column arrays of `GazeRecorder.PrimaryColumns` / `DiagnosticColumns` (Assets/Scripts/GazeRecorder.cs); the generator refuses to run when a column has no entry. Missing values are blank (= not measured); `0` / `0.0000` is a value. No NaN or placeholder is ever written.

* `gaze.csv`: **61** columns (v16: 143).  `gaze_diagnostics.csv`: **85** columns, one row per gaze row, joined by `session_id` + `frame_index` + `t_abs`.
